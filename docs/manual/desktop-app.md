# The desktop app

**Preview:** the desktop app is being built and is not part of a Rook release
yet. This page says what it is for; it will grow when the app ships.

The Rook desktop app sits in your computer's tray (Windows, macOS and Linux)
and keeps your hub one click away:

- **The dashboard in its own window**, signed in with your usual Rook login.
- **Quick ask**: a small box on a keyboard shortcut for asking the home agent
  something without opening the dashboard ([[manual-home-agent]]).
- **Notifications** when someone writes to you in a chat room
  ([[manual-chat]]).
- **Push-to-talk**: hold a key and speak instead of typing, using the voice
  service on your hub ([[manual-voice]]).
- **This computer's worker**: start and stop it from the tray
  ([[manual-adding-machines]]).
- **Install a hub on this computer**, for a first setup on Linux
  ([[manual-running-a-hub]]).

Nothing changes on the hub to use it. Until it ships, use the dashboard in
your browser.
