What is a worker?

A worker is a small agent that joins the ROOK band and exposes capabilities (shell, files, screenshot, hid, …). Once installed it appears on the Band tab, where you can snapshot, run shell, and more.

Linux / macOS

One line. Auto-installs Python deps, joins the band, and persists across reboots.

Windows (PowerShell, run on Windows)

Android — native app (recommended)

A real APK with a foreground service: real screen capture (MediaProjection) and rootless input (Accessibility).

  1. On the phone, open Download APK ↓
  2. Tap the file → allow “install unknown apps” for your browser → Install.
  3. Open Rook Worker, tap Start worker (hub/PSK prefilled).
  4. Grant screen capture, accessibility, and ignore battery optimization.
